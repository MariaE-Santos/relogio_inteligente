# relogio_inteligente

Atualmente, muitos idosos vivem sozinhos ou passam longos períodos sem supervisão, o
que aumenta o risco em casos de quedas. Em situações mais graves, a demora no socorro
pode trazer sérias consequências à saúde.
Diante disso, surge a necessidade de uma solução tecnológica acessível que seja capaz de
monitorar o idoso em tempo real, identificar quedas e acionar ajuda automaticamente
quando necessário.
Este projeto propõe o desenvolvimento de um relógio inteligente básico, utilizando
conceitos de programação e sensores, capaz de:
● Detectar quedas leves e graves;
● Monitorar batimentos cardíacos;
● Enviar alertas para responsáveis;
● Acionar emergência automaticamente em casos críticos.
